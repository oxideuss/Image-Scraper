# Security Policy

## Supported Versions

This project is in early development. We only support and patch the latest version of the code on the `main` branch.

## Reporting a Vulnerability

If you find a security vulnerability, **please do not open a public issue.** 

Instead, please report it privately using GitHub's **Private Vulnerability Reporting** feature. You can find this under the **Security** tab of this repository by clicking "Report a vulnerability".

Please include a description of the issue and steps to reproduce it. We will review your report as soon as possible.
